만든 앱을 **배포하고 운영하다 보면** 줄줄이 나오는 용어들을 모았어요. "배포 → 문제 → 되돌리기 → 재시도 → 키 폐기" 순서로 읽으면 한 이야기로 이어져요.

## Q. Docker가 뭐예요?

**A.** 프로그램과 **그 실행 환경을 하나의 상자(컨테이너)에 담아서**, 어디서든 똑같이 실행되게 해주는 도구예요.

> 📦 해외 배송용 **컨테이너 박스**예요. 규격화된 박스가 생기자 안에 뭐가 들었든 같은 크레인으로 옮길 수 있게 됐듯이, 앱을 환경째 상자에 넣으니 내 노트북이든 서버든 똑같이 돌아가요. "내 컴퓨터에서는 되는데요?"를 없애줘요.
{: .prompt-tip }

| 용어 | 뜻 | 비유 |
|---|---|---|
| 이미지 (Image) | 실행에 필요한 걸 담은 읽기 전용 설계도 | 붕어빵 틀 |
| 컨테이너 (Container) | 이미지를 실제로 실행 중인 것 | 틀로 구운 붕어빵 |
| Dockerfile | 이미지를 만드는 레시피 파일 | 붕어빵 레시피 |

```bash
docker build -t my-app .           # 이미지 만들기
docker run -p 8000:8000 my-app     # 컨테이너 실행 (내 포트 8000 ↔ 컨테이너 8000)
```

> ⚠️ 컨테이너를 지우면 안의 데이터도 사라지니 보존할 건 볼륨에 연결하고, **비밀 키를 이미지에 굽지 마세요.** 이미지를 받아 가는 누구나 볼 수 있어요.
{: .prompt-warning }

## Q. FastAPI가 뭐예요?

**A.** Python으로 API 서버를 빠르고 쉽게 만들게 해주는 웹 프레임워크예요. **타입 힌트만 써 두면 데이터 검증과 API 문서가 자동으로** 만들어져요.

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/hello/{name}")
def hello(name: str, age: int = 0):
    return {"message": f"안녕, {name}", "age": age}
# 실행: uvicorn main:app --reload  →  /docs 에서 자동 문서
```

`age=abc`를 보내면 `int`가 아니라서 **자동으로 422 에러**를 돌려줘요.

> 🍽️ 주문서 양식이 정해진 식당 주방이에요. 직원이 양식에 맞는지 먼저 확인하고(검증), 맞으면 주방(함수)으로 넘겨요. Flask는 가벼운 마이크로, Django는 풀스택이고 FastAPI는 **API·AI 모델 서빙에 특화**돼 있어요.
{: .prompt-info }

## Q. Artifact Registry가 뭐예요? (GCP)

**A.** 빌드한 결과물(Docker 이미지, 패키지 등)을 저장하고 관리하는 **창고**예요. 코드가 아니라 코드를 빌드해서 나온 **완성품**을 보관해요.

```
소스 코드 → (빌드) → 이미지 → push → [ Artifact Registry ] → pull → Cloud Run / GKE (실행)
```

> 📦 공장(빌드)에서 포장까지 끝난 상품(이미지)이 나오면 **물류 창고**에 입고하고, 배송 차량(Cloud Run)이 거기서 꺼내 가요. 이미지 주소의 `:TAG`는 버전 이름표라서 문제가 생기면 이전 태그로 되돌릴 수 있어요.
{: .prompt-tip }

예전의 Container Registry(gcr.io) 후속이에요. 저장소 단위로 권한을 줄 수 있으니 실행하는 쪽(Cloud Run)에는 **읽기 권한만** 주세요.

## Q. 롤백(Rollback)이 뭐예요?

**A.** 문제가 생겼을 때 **직전의 멀쩡했던 상태로 되돌리는 것**이에요.

> 🎮 게임의 **세이브 포인트**예요. 보스전에서 지면 처음부터 다시 하지 않고 마지막 저장 지점으로 돌아가요. 저장해 둔 지점이 없으면 돌아갈 곳도 없어요.
{: .prompt-tip }

| 영역 | 무엇을 되돌리나 |
|---|---|
| 데이터베이스 | 실행 중이던 트랜잭션 전체 취소 (ACID의 원자성) |
| Git | 코드 변경 이력 (`revert`, `reset`, `restore`) |
| 배포 | 새 버전을 내리고 이전 버전으로 복귀 |

```bash
git revert <커밋>          # "취소하는 새 커밋"을 만든다. 공유 브랜치에 안전
git reset --hard <커밋>    # 커밋 자체를 지운다. 이미 push한 브랜치엔 위험
```

> ⚠️ 이미 발송된 이메일이나 결제된 돈은 롤백이 안 돼요. 위험한 작업 전에는 백업과 확인 단계를 두세요.
{: .prompt-warning }

## Q. 리비전(Revision)은요?

**A.** 어떤 것의 수정된 판을 **하나씩 번호 붙여 기록한 것**이에요. "몇 번째로 고친 상태인가".

> 📚 책의 **개정판**이에요. 고칠 때마다 번호 붙은 판이 생기고, 옛 판을 남겨 두면 되돌아볼 수 있어요.
{: .prompt-tip }

SVN에선 저장소 변경 번호(`r1024`), Git에선 커밋 하나(`a1b2c3d`, `HEAD~2`), Cloud Run·Kubernetes에선 배포 설정의 한 판을 가리켜요. **버전**(`v2.1.0`)은 사용자에게 보이는 릴리스 이름, 리비전은 내부에 수시로 쌓이는 변경 기록이에요.

## Q. 카나리(Canary) 배포가 뭐예요?

**A.** 새 버전을 전체에게 한꺼번에 내보내지 않고 **소수에게만 먼저** 내보내 문제가 없는지 보고 점차 넓히는 배포 방식이에요.

> 🐤 **탄광의 카나리아**예요. 유독가스가 차면 사람보다 새가 먼저 쓰러져서 "나가자" 신호가 됐듯이, 소수의 사용자가 먼저 겪어서 전체에 퍼지기 전에 멈출 수 있게 해줘요.
{: .prompt-tip }

```
v2를 5%에게만 → 에러율·속도 관찰 → 25% → 50% → 100%
                       이상 있음 → 즉시 v1으로 롤백
```

| 방식 | 하는 일 | 단점 |
|---|---|---|
| 한 번에 교체 | 전원을 한꺼번에 | 문제 시 전원이 피해 |
| **카나리** | 소수 → 점진 확대 | 트래픽을 나누는 구성 필요 |
| 블루-그린 | 새 환경을 통째로 준비해 한순간에 전환 | 환경이 두 벌 필요 |
| 롤링 | 서버를 하나씩 교체 | 구·신버전이 섞이는 시간 존재 |

> "에러율 1% 넘으면 롤백"처럼 **되돌리는 기준을 미리 정해 두는 게** 핵심이에요.
{: .prompt-info }

## Q. Severity(심각도)는요?

**A.** 버그·취약점·장애가 **얼마나 심각한지** 등급으로 나타낸 거예요. 무엇부터 고칠지 정하는 기준이에요.

> 🏥 응급실의 **환자 분류(트리아지)**예요. 먼저 온 순서가 아니라 위급한 순서로 진료해요.
{: .prompt-tip }

| 등급 | 의미 | 예시 |
|---|---|---|
| Critical | 서비스 중단, 데이터 유출 | 결제 서버 다운 |
| High | 핵심 기능 고장, 우회로 있음 | 특정 환경에서 로그인 실패 |
| Medium | 일부 기능에 불편 | 정렬이 이상함 |
| Low | 사소함 | 오타 |

헷갈리는 짝은 **Priority**예요. Severity는 "얼마나 아픈가"(기술), Priority는 "언제 고칠까"(업무)예요. 회사 로고 오타는 심각도 Low여도 우선순위는 High일 수 있어요.

## Q. Dependabot이 뭐예요?

**A.** 프로젝트가 쓰는 라이브러리(의존성)의 **새 버전과 보안 취약점을 자동으로 감시**하고, 업데이트 PR을 대신 만들어 주는 GitHub의 봇이에요.

> 🧹 집 안 **소모품 점검 도우미**예요. "필터 교체 시기예요, 새것 가져다 놨어요"라고 올려두면, 갈아 끼울지(머지)는 내가 정해요.
{: .prompt-tip }

```yaml
# .github/dependabot.yml
version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "weekly"
```

> ⚠️ **자동 머지는 신중히** 하세요. 테스트가 부실하면 업데이트가 조용히 앱을 깨뜨릴 수 있고, 메이저 버전 업은 직접 확인해야 해요.
{: .prompt-warning }

## Q. 멱등성(Idempotency)이 뭐예요?

**A.** 같은 작업을 **한 번 하든 여러 번 하든 최종 결과가 똑같은** 성질이에요.

> 🛗 엘리베이터 "상승" 버튼은 몇 번 눌러도 결과가 같아요(멱등). 토글 스위치는 누를 때마다 바뀌어요(멱등 아님).
{: .prompt-tip }

| HTTP 메서드 | 멱등성 |
|---|---|
| GET(조회)·PUT(덮어쓰기)·DELETE(삭제) | ✅ 있음 |
| POST(새로 생성) | ❌ 없음 |

POST처럼 원래 멱등이 아닌 요청은 **멱등성 키(Idempotency Key)** 로 보완해요. 클라이언트가 요청마다 고유 ID를 헤더에 담아 보내면, 서버는 처음 본 키일 때만 실행하고 같은 키가 또 오면 **저장해 둔 결과를 그대로** 돌려줘요. 응답을 못 받은 상태에서도 이중 결제 걱정 없이 재시도할 수 있어요.

> 멱등성은 "항상 같은 응답"이 아니라 **"같은 서버 상태"** 예요. 두 번째 DELETE가 404여도 멱등이에요.
{: .prompt-info }

## Q. revoke가 뭐예요?

**A.** 이미 내어준 권한이나 자격(API 키, 토큰, 인증서)을 **취소해서 더는 쓸 수 없게** 만드는 거예요.

> 🔑 **호텔 카드키 분실 처리**예요. 프런트에 말해 그 키 번호를 무효로 하면, 주운 사람이 문에 대도 열리지 않고 나는 새 키를 받아요.
{: .prompt-tip }

```sql
GRANT SELECT ON users TO analyst;     -- 권한 부여
REVOKE SELECT ON users FROM analyst;  -- 권한 회수
```

> 🚨 **키가 깃에 올라갔다면 기록을 지우기 전에 먼저 revoke**하세요. 이미 복제됐을 수 있어서, 한 번이라도 공개한 키는 무조건 폐기하고 새로 발급해야 해요. 순서: revoke → 새 키 발급 → 사용 로그 확인 → `.env`를 `.gitignore`에 넣기.
{: .prompt-danger }

## Q. BYOK가 뭐예요?

**A.** Bring Your Own Key. 서비스가 주는 AI 대신 **내가 가진 API 키를 가져와서** 쓰는 방식이에요.

> 🍷 **콜키지 프리 식당**이에요. 식당(앱)은 자리와 서비스를 주고, 와인(API 키)은 내가 가져와요. 와인값은 가져온 곳(AI 회사)에 직접 내요.
{: .prompt-tip }

| | 앱이 AI 제공 (구독) | BYOK |
|---|---|---|
| 비용 | 앱에 월정액 | AI 회사에 쓴 만큼 직접 |
| 키 관리 | 앱이 알아서 | 내가 직접 발급·보관 |
| 단점 | 약정·선택 제한 | 키 관리 부담, 요금 예측 어려움 |

> ⚠️ 키는 비밀번호와 같아요. 콘솔에서 **월 사용 한도**를 꼭 설정하고, 유출되면 즉시 revoke하세요.
{: .prompt-warning }

## Q. Proxy(프록시)가 뭐예요?

**A.** 나와 상대 사이에 끼어서 **요청을 대신 전달해 주는 중간 서버**예요.

> 🧑‍💼 사장님에게 직접 전화하지 않고 **비서**를 거치는 거예요. 비서는 용건을 전달하고, 위험한 전화는 거르고, 같은 질문에는 메모해 둔 답으로 바로 답해요.
{: .prompt-tip }

| | 포워드 프록시 | 리버스 프록시 |
|---|---|---|
| 누구 대리인 | **클라이언트(나)** | **서버** |
| 상대가 보는 것 | 프록시 IP (내 IP 숨김) | 프록시 주소 (실제 서버 숨김) |
| 예시 | 회사 인터넷 프록시 | Nginx, Cloudflare |

```nginx
# 80번 포트로 온 요청을 내부 앱(8000)으로 전달
location / { proxy_pass http://127.0.0.1:8000; }
```

> FastAPI 앱을 `127.0.0.1`로 내부에만 열어 두고 **프록시만 외부에 공개**하는 구성이 흔해요. LLM 호출을 한곳에서 관리하는 "LLM 프록시"에 API 키를 두면 키가 앱에 노출되지 않아요.
{: .prompt-info }

## Q. 독스트링(Docstring)은요?

**A.** Python에서 함수·클래스·모듈의 첫 줄에 **삼중따옴표로 쓰는 설명 문자열**이에요. 일반 주석(`#`)과 달리 실행 후에도 남아있는 **진짜 문자열 객체**예요.

```python
def 인사(이름):
    """이름을 받아서 인사말을 돌려주는 함수."""
    return f"안녕하세요, {이름}님!"

print(인사.__doc__)  # 문자열로 조회 가능
```

> 📖 포스트잇 메모(주석)와 제품 상자 속 **정식 설명서**(독스트링)의 차이예요. IDE의 자동완성 툴팁과 `help()`가 이 독스트링을 읽어서 보여줘요.
{: .prompt-tip }

## 한 줄로 묶으면

앱을 **Docker**로 말아 **Artifact Registry**에 두고, **카나리**로 조금씩 내보내요. 문제가 생기면 **롤백**하고, **Severity**로 급한 것부터 고치고, **Dependabot**으로 라이브러리를 최신으로 유지해요. 재시도해도 안전하게 **멱등성**을 챙기고, 키가 새면 **revoke**해요.
