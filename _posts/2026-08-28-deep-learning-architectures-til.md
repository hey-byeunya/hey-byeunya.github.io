## Q. RNN과 CNN은 뭐가 다른가요?

**A.** 기본 신경망을 데이터 종류에 맞게 특화한 구조예요.

- **CNN** — 이미지 전문. 작은 필터로 부분부분 훑어 특징(선→모양→사물)을 층층이 조합해요. 그림 감정사의 돋보기 검사 🔎
- **RNN** — 순서 데이터 전문. 이전 정보를 기억하며 순차 처리해요. 소설을 순서대로 읽는 독자 📖

> RNN은 문장이 길어지면 앞부분을 잊는 문제가 있어요 — 원인은 아래 "기울기 소실". 요즘 LLM은 RNN 대신 트랜스포머를 써요.
{: .prompt-info }

## Q. 과적합(Overfitting)이 뭐예요?

**A.** 모델이 훈련 데이터를 너무 완벽하게 외워버려서, 새 데이터엔 오히려 못하는 현상이에요.

> 족보만 통째로 외운 학생 📝 — 기출문제는 100점, 새 문제는 0점. 회귀 그래프로 보면 점들을 억지로 다 지나가는 구불구불한 선이에요.
{: .prompt-warning }

해결책: 데이터 늘리기, 적당히 멈추기, 학습에 안 쓴 검증 데이터로 미리 확인하기.

## Q. 트랜스포머(Transformer)는 뭐가 특별해요?

**A.** RNN의 한계(느림·긴 문장을 잘 잊음)를 극복한 구조예요. 문장 전체를 동시에 보며, **Self-Attention**으로 모든 단어가 서로를 직접 참고해요.

> RNN = 옛날 전화 릴레이 게임(한 명씩 전달하다 왜곡됨). 트랜스포머 = 단체 채팅방(모두가 동시에 서로의 메시지를 봄). 💬
{: .prompt-tip }

트랜스포머 블록 하나 = **Self-Attention**(단어 간 관계 파악) + **FFN**(각 단어 개별 가공). 동시 처리라 순서 정보가 사라지는 문제는 **위치 인코딩**(각 토큰에 sin/cos로 만든 순서 번호표를 붙임)으로 보완해요.

논문 제목이 "Attention is All You Need"였고, GPT의 T가 바로 Transformer예요.

## Q. 기울기 소실(Vanishing Gradient)과 ResNet은요?

**A.**
- **기울기 소실** — 역전파로 오차를 거꾸로 전달할 때, 체인룰에서 1보다 작은 값을 계속 곱하다 보니 신호가 앞쪽 층에 도달할 즈음 거의 0이 되는 현상. RNN이 긴 문장의 앞부분을 잊는 진짜 원인이에요.
- **ResNet** — 잔차 연결(지름길)을 발명해서 이 문제를 해결한 CNN 구조. 원본 입력을 층을 건너뛰고 그대로 더해줘서, 아무리 깊게 쌓아도 신호가 안 죽어요. 🛣️

> 곱하기 대신 더하기라서 미분값이 1로 그대로 전달돼 소실되지 않아요. 이 '잔차 연결' 아이디어는 트랜스포머에도 그대로 쓰여요.
{: .prompt-tip }

## Q. FFN, FNN, LSTM은요? (이름이 헷갈려요)

**A.**
- **FFN(Feed-Forward Network)** — 트랜스포머 블록 안에서 Attention 다음에 오는, 각 토큰을 개별 가공하는 부품. 사실 퍼셉트론 두 층일 뿐이에요.
- **FNN(Feedforward Neural Network)** — "정보가 한 방향으로 흐르는 신경망" 전체를 가리키는 큰 분류(카테고리). FFN은 그 안의 부품 하나.
- **LSTM** — RNN에 "기억할지 잊을지 결정하는 문(게이트)"을 추가한 개선 구조. 망각·입력·출력 게이트로 중요한 정보만 오래 유지해요. 🚪

> FFN(부품) vs FNN(카테고리) — 이름이 비슷해도 가리키는 범위가 달라요!
{: .prompt-warning }
