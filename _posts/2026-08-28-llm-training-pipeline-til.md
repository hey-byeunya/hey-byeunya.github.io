## Q. 사전학습(Pre-training)이 뭐예요?

**A.** 인터넷의 방대한 텍스트로 "다음 단어 예측"을 수조 번 반복 훈련시켜, LLM에게 언어 능력의 기초를 만들어주는 가장 크고 오래 걸리는 학습 단계예요.

> 아기가 방대한 어른들의 말을 들으며 스스로 패턴을 터득하는 것과 같아요 👶. 사전학습만 끝난 모델은 똑똑하지만 "눈치 없는" 상태 — 질문에 답하는 대신 그냥 다음 말을 이어써요.
{: .prompt-info }

## Q. 스케일링 법칙, 인컨텍스트 러닝·퓨샷은요?

**A.**
- **스케일링 법칙** — 모델 크기·데이터·계산량을 키우면 성능이 예측 가능하게(멱법칙 형태로) 좋아진다는 경험적 법칙. 운동량↑ → 근력↑ 예측 가능한 것과 비슷해요 💪
- **인컨텍스트 러닝·퓨샷** — 프롬프트 안의 예시만으로, **가중치 변경 없이** 즉석에서 패턴을 파악해 응용하는 능력. "1→A, 2→B, 3→C" 보여주면 "5는?"에 바로 E라고 답하는 것과 같아요.

| 이름 | 예시 개수 |
|------|:---:|
| 제로샷 | 0개 |
| 원샷 | 1개 |
| 퓨샷 | 여러 개(2~5개) |

> 핵심: 가중치가 안 바뀐다는 점에서 파인튜닝과 정반대예요. 모델이 클수록(스케일링 법칙) 이 능력이 강해져요.
{: .prompt-tip }

## Q. 사후 훈련(Post-training)은 뭘 묶는 말이에요?

**A.** 사전학습 이후 모델을 다듬는 **모든 과정**을 부르는 상위 개념이에요.

```
사전학습 → 사후 훈련
              ├── 후속 사전훈련 (특정 분야 텍스트로 한 번 더 심화)
              ├── 지도학습 미세조정(SFT) — 질문-모범답 형식 가르치기
              ├── 매개변수 효율적 미세조정(PEFT) — 일부만 학습해 비용↓
              └── 선호도 조정 — RLHF·DPO를 아우르는 이름
```

- **DPO** — RLHF처럼 별도 보상모델을 만들지 않고, 선호도 데이터로 곧장 모델을 조정하는 더 간단한 방법.

## Q. 매개변수와 초매개변수는 뭐가 달라요?

**A.**
- **매개변수(Parameter)** — 가중치·bias처럼, 훈련 중 역전파로 **스스로 학습되는 값**.
- **초매개변수(Hyperparameter)** — 학습률·층 개수·배치 크기처럼, 훈련 **시작 전에 사람이 미리 정해두는** 설정값.

> 매개변수 = 공부해서 늘어나는 학생의 실력. 초매개변수 = 부모님이 미리 짜준 학습 계획표(하루 몇 시간, 어떤 문제집)예요.
{: .prompt-tip }

"파라미터 700억 개 모델"이라고 할 때의 파라미터가 바로 이 매개변수(가중치·bias) 개수예요.

## Q. 매개변수 효율적 미세조정(PEFT)은 왜 필요해요?

**A.** 원래 매개변수 전부를 다시 학습시키면 계산이 너무 비싸요. PEFT는 원본은 대부분 얼려두고(freeze), 아주 작은 부품만 새로 붙여서 그것만 학습해요(예: LoRA).

> 원본 문서에 포스트잇만 붙이는 것 📌 — 책 전체를 다시 쓰는 대신, 필요한 부분에 메모만 추가해요.
{: .prompt-tip }

## Q. 파국적 망각(Catastrophic Forgetting)이 뭐예요?

**A.** 새로운 걸 학습시키면, 모델이 예전에 배운 걸 갑자기·심각하게 잊어버리는 현상이에요. 매개변수가 여러 지식에 공유되어 있어서, 새로 조정하면 예전 값이 덮어써지기 때문이에요.

> 같은 캔버스에 새 그림을 덧칠하면 밑에 있던 예전 그림이 지워져요 🎨. 과적합(한 작업 안에서의 문제)과 달리, 파국적 망각은 **여러 작업 사이**의 문제예요.
{: .prompt-warning }

PEFT가 원본 매개변수를 보존하는 방식이라, 계산 비용뿐 아니라 이 파국적 망각도 함께 막아줘요.

## Q. 멱법칙, 양자화는요?

**A.**
- **멱법칙(Power Law)** — 한 값이 다른 값의 거듭제곱에 비례하는 관계(y=x^n). 지진 규모, 도시 인구처럼 급격하지만 규칙적인 변화예요. 스케일링 법칙이 정확히 이 형태를 따라요.
- **양자화(Quantization)** — 모델 가중치를 32비트→8비트/4비트로 뭉뚱그려 저장해서 훨씬 가볍고 빠르게 만드는 기술. 고화질 사진 압축과 같아요 📸. 덕분에 노트북·핸드폰에서도 LLM 실행이 가능해져요.
