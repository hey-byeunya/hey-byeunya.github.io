## Q. OCR(Tesseract·PaddleOCR)이 뭐예요?

**A.** 이미지 속 글자를 편집·검색 가능한 진짜 텍스트로 바꿔주는 기술이에요. **Tesseract**는 Google의 오래되고 안정적인 오픈소스 엔진, **PaddleOCR**은 Baidu의 최신 딥러닝 기반 도구(한국어 등에 강함)예요.

> MNIST가 "숫자 하나"를 인식했다면, OCR은 문서 전체에서 "글자 위치 찾기 + 인식"을 한 번에 하는 확장판이에요. 📷➡️📝
{: .prompt-info }

## Q. 객체 탐지(Object Detection)와 YOLO는요?

**A.**
- **객체 탐지** — 사진 속에 무엇이 있는지(분류) + 어디에 있는지(위치, 박스)를 동시에 찾는 기술. 숨은그림찾기 채점 선생님처럼요 🔍
- **YOLO(You Only Look Once)** — 사진을 딱 한 번만 보고, 격자로 나눠 모든 물체를 동시에 예측하는 실시간 탐지 모델. 화면 전체를 한 번에 쫙 훑어보는 베테랑 경비원 👁️

> 이전 방식은 후보 영역을 여러 번 훑어봐서 느렸지만, YOLO는 격자 전체를 동시에 계산해서 자율주행·CCTV 같은 실시간 처리에 필수예요.
{: .prompt-tip }

## Q. IoU는 뭘 재는 건가요?

**A.** 예측한 박스와 정답 박스가 얼마나 겹치는지를 "교집합÷합집합"으로 수치화한 채점 지표예요(0~1).

> 다트 과녁 판정 🎯 — 목표와 던진 위치가 많이 겹칠수록 IoU가 높아져요. YOLO에서 같은 물체를 중복으로 잡은 박스를 정리할 때도 쓰여요.
{: .prompt-tip }

## Q. VLM(Vision-Language Model)이 뭐예요?

**A.** 이미지 인식(CNN 계열)과 언어 이해(LLM·트랜스포머)를 결합해, 이미지를 보고 이해·설명·대화까지 할 수 있는 AI예요. 이미지를 "이미지 토큰"으로 변환해 텍스트 토큰과 함께 트랜스포머에서 처리해요.

> CNN만 있으면 그림은 알아봐도 대화를 못 하고, LLM만 있으면 말은 잘해도 그림을 못 봐요. VLM은 이 둘을 합친 거예요. 🎨🗣️ (Claude, GPT-4V, LLaVA 등)
{: .prompt-tip }

## Q. 시맨틱·인스턴스·파놉틱 분할은 뭐가 다른가요?

**A.** 객체 탐지의 박스보다 정밀하게, 픽셀 단위로 구분하는 세 가지 방식이에요.

| | 종류 구분 | 개체 구분 | 배경 표시 |
|---|:---:|:---:|:---:|
| 시맨틱 분할 | ✅ | ❌(뭉침) | ✅ |
| 인스턴스 분할 | - | ✅ | ❌(물체만) |
| 파놉틱 분할 | ✅ | ✅ | ✅ |

> 시맨틱=색칠공부("자동차는 파랑, 사람은 빨강"). 인스턴스=이름표 색칠("사람1은 빨강, 사람2는 주황"). 파놉틱=완벽한 지도(개별 건물+배경까지 전부). 🗺️
{: .prompt-tip }

## Q. FCN·U-Net·Mask R-CNN·SAM은 뭐가 다른가요?

**A.** 분할(Segmentation)을 실제로 수행하는 대표 모델들의 발전사예요.

| 모델 | 연도 | 특징 |
|------|:---:|------|
| FCN | 2015 | 최초로 픽셀 단위 분할 가능케 함 |
| U-Net | 2015 | U자 구조 + 지름길로 정밀도 향상 (의료영상 기원) |
| Mask R-CNN | 2017 | 객체 탐지 + 마스크로 인스턴스 분할 |
| SAM | 2023 | 제로샷으로 아무거나 분할 |

> SAM의 "학습 안 한 물체도 분할 가능"한 능력은 대규모 사전학습 + 스케일링 법칙의 제로샷 효과가 이미지 분할에서 실현된 사례예요.
{: .prompt-info }
