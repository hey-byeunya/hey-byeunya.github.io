## Q. Hugging Face, Gradio, ngrok은 뭐예요?

**A.**
- **Hugging Face** — AI 모델·데이터셋을 공유하는 플랫폼. "AI계의 GitHub"예요 🤗. 처음부터 사전학습을 다시 할 필요 없이 이미 훈련된 모델을 받아 쓰거나 살짝만 파인튜닝해요.
- **Gradio** — AI 모델용 웹 데모 화면을 코드 몇 줄로 만들어주는 Python 라이브러리. 조립식 가구 세트처럼요 🪑. Hugging Face Spaces의 데모 대부분이 이걸로 만들어졌어요.
- **ngrok** — 내 컴퓨터의 로컬 서버를 임시로 전 세계 공개 주소로 만들어주는 터널링 도구. 아파트 정문에 임시 접수처를 세우는 것 🚇

> Gradio로 로컬 데모를 만들고, ngrok으로 잠깐 공개하는 조합이 흔해요.
{: .prompt-tip }

## Q. CPU와 GPU는 왜 다르게 쓰여요?

**A.** CPU는 소수의 강력한 코어로 복잡한 작업을 순서대로, GPU는 수천~수만 개의 단순한 코어로 단순 작업을 한꺼번에 병렬 처리해요.

> CPU=박사 몇 명(복잡한 문제를 혼자 척척). GPU=초등학생 만 명(각자는 단순하지만 동시에 풀면 훨씬 빠름) 🎓
{: .prompt-tip }

신경망 계산(곱셈·덧셈을 수십억 번)은 "단순 계산의 대량 반복"이라 GPU에 딱 맞아요. 원래 게임 그래픽용이던 GPU가 AI 시대의 핵심 엔진이 된 이유예요.

## Q. 제로 데이터 보존(ZDR)이 뭐예요?

**A.** AI 서비스가 고객이 API로 보낸 대화·데이터를 처리 후 저장하지 않고 즉시 삭제하겠다고 보장하는 정책이에요.

> 상담이 끝나자마자 서류를 파쇄기에 넣는 것 🔥 — 의료·금융·법률처럼 민감 정보를 다루는 기업 고객에게 중요한 계약 조건이에요.
{: .prompt-info }

## Q. PoC와 스모크 테스트는 뭐가 다른가요?

**A.**
- **PoC(Proof of Concept)** — "이게 기술적으로 가능한지"만 빠르게 확인하는 초소형 실험. 실제 사용자 대상이 아니에요. 🧪
- **스모크 테스트** — 배포/빌드 직후 "기본 기능이 살아있는지" 빠르게 확인하는 테스트. 전자회로에 전원 넣고 연기 안 나는지 보던 것에서 유래했어요 🔥

| | PoC | 스모크 테스트 |
|---|---|---|
| 시점 | 개발 시작 전 | 배포/빌드 직후 |
| 확인 대상 | 아이디어가 되는지 | 이미 만든 게 안 망가졌는지 |

> PoC는 "만들기 전" 가능성 확인, 스모크 테스트는 "만든 후" 정상 작동 확인 — 순서상 완전히 다른 단계예요.
{: .prompt-warning }

## Q. T자형 학습이 뭐예요?

**A.** 여러 분야를 넓게(가로줄) 아우르면서, 한 분야는 깊게(세로줄) 파고드는 학습 모델이에요.

> 만능 요리사 겸 파스타 장인 🍝 — 한식·중식·일식·양식을 다 조금씩 하면서, 파스타만큼은 세계 최고 수준으로 깊이 파요.
{: .prompt-tip }

| 모양 | 특징 |
|------|------|
| I자형 | 한 분야만 깊고, 다른 분야는 모름 |
| 막대형 | 여러 분야를 알지만 다 얕음 |
| T자형 | 넓은 지식 + 한 곳은 깊음 (이상적) |
