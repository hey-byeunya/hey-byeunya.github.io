## Q. 월드모델(World Model)이 뭐예요?

**A.** AI가 "행동하면 다음에 어떻게 될지"를 내부에 시뮬레이션처럼 학습해두는 것이에요. 실제로 해보지 않고도 결과를 미리 그려볼 수 있어요.

```
현재 상태(s) + 행동(a) → [월드 모델] → 다음 상태(s')
```

> 체스 고수의 머릿속 수읽기 ♟️ — "이 수를 두면 상대는 이렇게 두겠지"를 실제로 두지 않고 미리 시뮬레이션하는 것과 같아요.
{: .prompt-tip }

자기회귀(다음 토큰 예측)와 같은 발상을 "다음 단어"가 아니라 "다음 세상 상태"에 적용한 거예요. 최근 Sora 같은 동영상 생성 모델이 물리 법칙을 스스로 터득하는 현상으로 주목받고 있어요.

## Q. fair-code 방식은요?

**A.** 오픈소스처럼 코드는 공개하되, "그걸로 경쟁 상업 서비스를 만드는 것"만 제한하는 라이선스 철학이에요.

| | 완전 폐쇄형 | fair-code | 완전 오픈소스(OSI) |
|---|---|---|---|
| 코드 열람 | ❌ | ✅ | ✅ |
| 경쟁 상업 서비스로 재판매 | (코드 없음) | ❌ 제한됨 | ✅ 허용됨 |

> ⚠️ 엄밀히는 OSI 인정 "진짜 오픈소스"는 아니고 "소스 공개(source-available)"에 가까워요. 큰 클라우드 회사가 오픈소스를 그대로 가져다 유료 서비스로 되파는 "무임승차" 문제 때문에 나왔어요. 대표 사례: n8n.
{: .prompt-info }

## Q. ULW(Ultra Work)가 뭐예요?

**A.** Oh My OpenAgent(OmO)라는 AI 에이전트 하네스에서, 채팅창에 "ulw" 세 글자만 입력하면 트리거되는 완전 자율 실행 모드예요.

```
"ulw" 입력
   → 자동 계획 수립 + 심층 리서치 + 병렬 에이전트 + 자기 수정 루프
   → "돌봄 제로"로 알아서 끝까지 진행
```

> Sisyphus(총괄 코디네이터)가 진행 상황을 추적하며, Prometheus(계획)·Atlas(실행)·Hephaestus(깊은 작업) 같은 전문 에이전트에게 일을 나눠줘요.
{: .prompt-tip }

## Q. MBPP는요?

**A.** "Mostly Basic Python Problems"의 약자로, AI가 자연어 설명을 보고 짠 파이썬 코드를 테스트 케이스로 자동 채점하는 벤치마크예요.

```
문제: "리스트에서 짝수만 걸러내는 함수를 짜세요"
   → AI가 코드 생성 → 테스트 케이스 3개 실행 → 전부 통과해야 정답
```

| | MBPP | HumanEval |
|---|---|---|
| 만든 곳 | Google | OpenAI |
| 난이도 | 초급 위주 | 조금 더 어려움 |
| 문제 수 | ~1,000개 | ~164개 |

## Q. .ipynb는 뭔가요?

**A.** Jupyter Notebook 파일 확장자예요. 코드와 실행 결과(그래프·표), 설명 글을 셀 단위로 섞어 기록하는 대화형 문서예요.

> 요리 실험 노트 📔 — "1단계 재료 손질 → 사진 첨부", "2단계 볶기 → 중간 맛 메모"처럼, 과정과 결과를 그 자리에서 바로바로 확인해요.
{: .prompt-tip }

파일 내부는 사실 JSON 형식으로 저장되고, 마크다운 문법도 섞어 쓸 수 있어요. Google Colab, VS Code 등에서 열어 쓸 수 있어요.

## Q. NLP는 뭐예요?

**A.** 자연어 처리(Natural Language Processing) — 컴퓨터가 사람의 언어를 이해·생성하도록 다루는 AI 분야예요.

> "AI ⊃ 머신러닝 ⊃ 딥러닝"이 **방법(어떻게 푸나)** 축이라면, NLP는 **분야(무엇을 다루나)** 축이에요. 완전히 다른 질문이라 서로 포함관계가 아니에요.
{: .prompt-warning }

토큰화·임베딩·트랜스포머·LLM이 전부 NLP 기술의 발전 결과물이고, 컴퓨터 비전(CNN·YOLO)과는 형제 분야예요. 둘은 VLM에서 다시 만나요.

```
규칙 기반 → 통계·머신러닝 → RNN → 트랜스포머 → LLM
```
